# DEPENDENCIES

Ocean Hackathon Cork 2026 — Challenge: _Seeing the Invisible Shield: Valuing
Coastal Habitats as Natural Infrastructure_

This file exists because the official rules require every third-party library
and dataset to be declared with its version and its licence. It has two kinds
of content and they must not be confused:

- **The Python package table is generated**, not written. Run
  `python src/make_dependencies.py` to rebuild it. Never edit it by hand — a
  version number typed from memory is a fabricated fact in a compliance
  document.
- **Everything else is hand-written** and must be maintained deliberately.

Every entry carries a **verification status**. `VERIFIED` means the licence was
read from the publisher's own metadata or licence page. `UNREAD` means nobody
has checked, and nothing may be published from that source until they have.

## 6. Licence compatibility — one thing to be careful about

Two entries above are **copyleft**, and they behave differently from the CC BY
sources:

- **QGIS is GPL-2.0-or-later.** Using it to inspect data is unrestricted.
  Copying code out of it into our prototype is not.
- **OpenStreetMap is ODbL 1.0**, which is share-alike _for databases_. If OSM
  geometry becomes part of the valuation database we distribute, the obligation
  travels with it.

Everything else in §3 is CC BY 4.0 or equivalently permissive: attribution is
required, and there is no share-alike obligation. That is why the attribution
strings in §4 are not optional decoration — they are the entire compliance
requirement for those sources.

## 7. How to regenerate

```bash
cd ~/Desktop/OCEANHACKATHON
source .venv/Scripts/activate

python src/make_dependencies.py --selftest    # offline checks
python src/make_dependencies.py               # rewrite section 1
python src/make_dependencies.py --print       # preview without writing
```

The script only replaces the text between the two `AUTOGENERATED` markers.
Sections 2 to 7 are hand-written and are preserved untouched — it refuses to
run at all if the markers are missing, rather than overwriting prose.

If a new library is imported anywhere in `src/`, add it to `ROOTS` in
`src/make_dependencies.py` and regenerate. Transitive dependencies are found
automatically and do not need to be added.
