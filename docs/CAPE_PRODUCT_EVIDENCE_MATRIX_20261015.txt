REPRODUCTION AND PRESERVATION
1. Run REBUILD_DEMO.bat --no-pause using the existing Python environment.
2. Run CHECK_DEMO.bat --no-pause under normal Windows permissions.
3. Launch START_DEMO.bat, or open outputs/map/index.html offline.
4. In stage 6 generate a report of the current settings; download HTML/JSON or Print/Save PDF.
The prior working web app is archived in previous_working_app.zip. Raw imagery, sonar/bathymetry downloads, research, frozen tests and final media were not duplicated or altered. New compact derived views reuse those inputs. The rebuild audit now writes to the new product folder, not the historical overnight research folder.
